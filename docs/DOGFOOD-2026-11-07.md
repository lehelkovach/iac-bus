# Dogfood: two runners, three real tasks, one clone (2026-11-07)

The question: does the bus coordinate real work on a real repo, not a scratch
one? Setup:

- A clone of this repository on the packaging branch.
- Three genuine maintenance tasks queued on the hosted bus
  (`https://129-146-105-237.sslip.io`, over HTTPS from a Claude Code cloud
  container), each naming the file it would touch:
  1. `.github/workflows/prod-deploy.yml`: the deploy job used `secrets` in a
     job-level `if:`, which GitHub Actions does not allow, so it could never
     run. Apply the gate-in-the-step fix `dev-deploy.yml` already uses.
  2. `docs/AGENT_TASKS.md`: stale since August; rewrite it from
     `docs/PROGRESS.md` and `docs/OCI-LIVE.md`.
  3. `tests/test_bus.py`: add tests for the new `/health` fields and
     `/metrics` counters, and make the file pass.
- Two runners (`iac-bus-runner --once`, Sonnet) started at the same time on
  the same queue and the same clone, each allowed to run this repo's pytest.

## What happened

Runner 1 took tasks 1 and 3; runner 2 took task 2. Each task ran in its own
Claude Code session with its own run token. Every session locked exactly the
file it was told about before editing, released it after, and reported status.

## Review

All three diffs were accepted into this repository without changes:

- The workflow fix is the same pattern as `dev-deploy.yml`, and the file still
  parses. (The agent noted it could not run the workflow to confirm, which is
  correct: workflows are manual-only.)
- The two tests follow the file's existing helper and style; the file passes
  (13 tests).
- The backlog rewrite is accurate against the current docs and 78 lines long.

What the bus did and did not do here:

- Locks were taken and released correctly, but no two tasks touched the same
  file, so no conflict arose. The collision case is covered by the trial and
  by `scripts/bench.py` (`docs/BENCHMARKS.md`).
- Nothing needed a decision, so no human was asked.
- The runner held each queue lease for the session's duration. (Lease renewal
  landed after this run; before it, a session longer than the lease could have
  had its item claimed twice.)

Cost: about $0.25 of model time for the three tasks.
